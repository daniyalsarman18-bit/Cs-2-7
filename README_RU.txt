BALDYREX SO2 — облачная сборка IPA с iPhone

Это отдельное демонстрационное приложение. Переключатели ESP / NO RECOIL / AIM ASSIST только меняют своё состояние в интерфейсе и не воздействуют на Standoff 2.
Плавающая кнопка работает внутри приложения. iOS не разрешает обычному приложению показывать произвольное окно поверх другой игры.

Как собрать с iPhone:
1. Создай репозиторий GitHub и загрузи туда ВСЕ файлы и папку .github из этого архива.
2. Открой репозиторий на GitHub в Safari.
3. Перейди во вкладку Actions → Build unsigned iOS IPA.
4. Нажми Run workflow и дождись зелёного статуса.
5. Открой завершённый запуск, найди Artifacts и скачай BaldyrexSO2-unsigned-IPA.
6. Распакуй скачанный артефакт. Полученный IPA нужно подписать своим сертификатом в KSign перед установкой.

Важно: этот workflow создаёт неподписанный IPA. Для установки на iPhone требуется действительная подпись. Самостоятельно в GitHub не вводи Apple ID, пароль или приватные ключи в сторонние Actions.
